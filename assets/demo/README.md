# Demo Assets

Add rendered project videos here to activate the project-page demo viewer.

Expected files:

- `representation-analysis.mp4`
- `nvs-results.mp4`

Optional poster images:

- `representation-analysis.jpg`
- `nvs-results.jpg`

The project page checks for these files at load time and shows a placeholder when a video is missing.

After adding a video, set its `available` field to `true` in `docs/demo.js`.
